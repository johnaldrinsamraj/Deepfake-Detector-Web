System Information

About

Audio Deepfake & Synthetic Media Detector

Architecture

Phase 1: Data Pipeline — Source collection, synthetic generation via TTS engines (Bark, Coqui, edge-tts), Voice Activity Detection, fixed-duration segmentation, speaker-disjoint train/val/test splitting (70/15/15).

Phase 2: Feature Extraction & Models — MFCCs, Mel-Spectrograms, Log-Mel-Spectrograms via librosa. Deep embeddings via Wav2Vec2/HuBERT. Three model options: 2D CNN, ResNet18, Wav2Vec2 fine-tuned head.

Phase 3: Calibration — Temperature scaling for calibrated probability outputs. Accuracy, Precision, Recall, ROC-AUC, Confusion Matrix evaluation.

Phase 4: Dashboard — Interactive web interface with drag-and-drop upload, real-time waveform & spectrogram visualization, verdict display with spectral evidence.

Getting Started

# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate synthetic training data
python generate_synthetic.py

# 3. Train the model
python train_full.py --model_type cnn --epochs 30

# 4. Launch the web dashboard
python web_app.py  # opens at http://localhost:9011
